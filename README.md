# Eagle-Konbu Tap

## How do I install these formulae?

`brew install eagle-konbu/tap/<formula>`

Or `brew tap eagle-konbu/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "eagle-konbu/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
